Sequencing was performed on the Illumina Novaseq6000 platform using a paired-end 150 bp (PE150) strategy.

Cleaned reads were aligned to the mouse reference genome (NCBI build 37, mm9) using Bowtie2 (version 2.4.4) (Langmead et al., 2009), and duplicate alignments were removed using the MarkDuplicates tool in Picard (version 2.25.0).
