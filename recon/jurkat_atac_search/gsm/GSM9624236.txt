!Sample_extract_protocol_ch1 = CUT&RUN was performed on 0.1 – 0.5 million CD34+ HSPCs using the CUTANA ChIC/CUT&RUN kit from EpiCypher (#14-1048-24) following manufacturer’s instructions.
!Sample_extract_protocol_ch1 = ATAC-seq was performed with 50,000 cells using the Omni-ATAC protocol as described (Corces et al., 2017). Cells were washed once with 1X PBS and then lysed in 50µl cold Cell Lysis Buffer containing 0.01% digitonin for 3 minutes on ice. After cell lysis, 1mL cold Resuspension Buffer was added and cells were immediately spun at 600xg for 10 minutes at 4°C. After removing the supernatant, the nuclei were transposed in 50µl Transposition reaction using the Tn5 enzyme from Illumina for 30 minutes at 37°C. Transposed DNA was purified using a Qiagen MinElute PCR clean-up kit and DNA was eluted in 10µl Elution Buffer.
!Sample_extract_protocol_ch1 = CD34+ HSPCs were harvested following DMSO or dTAGV-1 treatment and resuspended in TRI Reagent (Sigma). RNA was isolated using the Direct-zol RNA miniprep kit (Zymo Research #R2050). For BRU-seq, cells were lysed directly in Trizol followed by isolation of total RNA and treatment with DNAse (TURBO DNA-free Kit; Invitrogen). The Bru-labeled RNA was immunocaptured using anti-BrdU antibodies (BD Biosciences).
!Sample_extract_protocol_ch1 = Libraries were constructed using library prep kits from EpiCypher (#14-1001) following manufacturer’s instructions.
!Sample_extract_protocol_ch1 = Libraries were constructed by amplifying eluted DNA with barcoded primers described in Corces et al., 2017 for 10-12 cycles. The optimal number of cycles was determined by performing a quantitative PCR analysis after the initial 5 PCR cycles. Amplified libraries were purified using AMPure beads to remove fragments less than 200bp and larger than 700 bp. Final barcoded libraries were pooled and sequenced in paired-end mode.
!Sample_extract_protocol_ch1 = CD34+ HSPCs: RNA was quantified using the Quant-iT RiboGreen RNA assay (ThermoFisher) and quality checked by the 2100 Bioanalyzer RNA 6000 Nano assay (Agilent) or 4200 TapeStation High Sensitivity RNA ScreenTape assay (Agilent) prior to library generation. Libraries were prepared from total RNA with the Illumina Stranded Total RNA Library Prep Kit according to the manufacturer’s instructions (Illumina, PN 20040529). Libraries were analyzed for insert size distribution using the 2100 BioAnalyzer High Sensitivity kit (Agilent), 4200 TapeStation D1000 ScreenTape assay (Agilent), or 5300 Fragment Analyzer NGS fragment kit (Agilent). Libraries were quantified using the Quant-iT PicoGreen ds DNA assay (ThermoFisher) or by low pass sequencing with a MiSeq nano kit (Illumina). Paired end 100 cycle sequencing was performed on a NovaSeq X Plus (Illumina).
!Sample_extract_protocol_ch1 = Jurkat (BRU-seq): Strand-specific libraries were prepared from a modified protocol using the TruSeq Kit (Illumina) as previously described (Paulsen et al., 2013)

!Sample_data_processing = Raw paired-end reads were quality trimmed and adapter trimmed using TrimGalore (v0.4.4) with a quality score cutoff of Q20. Quality trimmed reads were mapped to the GRCh38 reference genome with BWA (v0.7.12-r1039) and converted to bam format using samtools64 (v1.2). Duplicate reads were marked using biobambam2 (v2.0.87). Properly paired and uniquely mapped reads were extracted by samtools (-F 1804 -b -q 1) and converted to paired-end fragment intervals (BEDPE). For coverage calculation, fragments with inferred insert size < 2000 bp were counted and used to compute a library-size scaling factor to normalize signal to a fixed library size. The center 80 bp of these fragments were used to generate genome-wide coverage tracks using bedtools genomecov in bedGraph format (-bg), applying the scaling factor for depth normalization (-scale). BedGraph files were converted to BigWig format using UCSC tools (bedGraphToBigWig) for visualization in IGV and for creating heatmaps. To increase detection of BCL11BdTAG and RUNX1 binding events in CD34+ HSPCs without DMSO or dTAGV-1 treatment, the mapped bam files from both replicates were merged prior to downstream processing.
!Sample_data_processing = Raw paired-end reads were quality trimmed and adapter trimmed using TrimGalore (v0.4.4) with a quality score cutoff of Q20. The first 15 bp of each read were clipped to reduce the GC bias introduced by the Tn5 enzyme. Quality trimmed reads were mapped to the GRCh38 reference genome with BWA (v0.7.12-r1039) and converted to bam format using samtools64 (v1.2). Duplicate reads were marked using biobambam2 (v2.0.87). Properly paired and uniquely mapped reads were extracted by samtools (-F 1804 -b -q 1). The center 80 bp of nucleosome-free fragments (fragment size < 109 bp) were extracted using bedtools and converted to scaled genome coverage tracks for visualization on IGV and in heatmaps. The scaling factor was computed from the total number of nucleosome-free fragments to normalize signal to a fixed library size. Peaks were called with MACS2 (v2.1.1.20160309) using nucleosome-free fragments with parameters -f BEDPE --keep-dup all -q 0.01
!Sample_data_processing = For CD34+ HSPCs: Paired-end RNA-seq reads were adapter and quality trimmed using Trim Galore (v0.4.4), and read quality was assessed with FastQC. Reads were aligned to the GRCh38 reference genome with STAR (v2.7) in two-pass mode. Coordinate-sorted BAM files, transcriptome alignments, gene counts, and strand-specific RPM-normalized coverage tracks were generated during alignment, and wiggle files were converted to BigWig format using wigToBigWig. Duplicate reads were marked with GATK MarkDuplicates, alignments were indexed with SAMtools, and RNA-seq quality metrics were collected using Picard CollectRnaSeqMetrics. Gene- and isoform-level expression was quantified with RSEM. Differential expression analysis was performed using the edgeR/limma-voom workflow. Genes with counts per million (CPM) ≥ 1 in at least 3 samples were retained using edgeR, and normalized expression values were generated by voom as log2-counts per million. Differentially expressed genes between treatment groups and transduction conditions were identified using linear models with empirical Bayes moderation implemented in limma.
!Sample_data_processing = For Jurkat BRU-seq: Reads were pre-mapped to the ribosomal RNA (rRNA) repeating unit (GenBank U13369.1) and the mitochondrial and EBV genomes (from the hg38 analysis set) using Bowtie2. Unaligned reads were subsequently mapped strand-specifically to human genome build hg38/GRCh38 using STAR and GENCODE annotation version 27. Gene expression was quantified as previously described (Magnuson et al., 2022) and differential gene expression was performed using DESeq2.
