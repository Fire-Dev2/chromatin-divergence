!Sample_treatment_protocol_ch1 = Jurkat cells were stimulated for 2 hours with 50 ng/ml PMA (Sigma-Aldrich) and 500 ng/ml ionomycin (Sigma, Aldrich). Lentivirus transduction was conducted using either sgCtrl_P258 (control guide RNA) or sg70_P260 (RE4 base editing guide RNA) constructs. Cells were plated at a density of 2-5 x 10^5 cells and treated with lentiviral supernatant supplemented with 8 ug/ml polybrene, centrifuged at 2000g 32 C for 60 minutes, and incubated overnight at 37C 5% CO2. Cells were changed into complete RMPI the following day and puromycin selection was conducted using 5 ug/ml for 3 days.
!Sample_growth_protocol_ch1 = Jurkat cells were grown in 37C, 5% CO2 in complete RPM consisting of RPMI (GIBCO), 10% fetal bovine serum (FBS, heat inactivated, Peak Serum), 20 mM HEPES (GIBCO), 1% sodium pyruvate (GIBCO), 1% penicillin-streptomycin (GIBCO), 1% NEAA (GIBCO), at a maximum density of 2 x 10^6 cells. Cells were routinely tested for mycoplasma.
!Sample_molecule_ch1 = genomic DNA
!Sample_extract_protocol_ch1 = Nuclei from 50000 cells per sample were isolated using ATAC-seq lysis buffer (10 mM Tris-HCL, 10 mM NaCl, 3mM MgCl2, 0.1% Tween-20, 0.1% NP40, 0.1% Digitonin, 1% BSA and ddH2O), wash buffer (10 mM-Tris-HCl, 10 mM NaCl, 3 mM MgCl2, 1% BSA, and ddH2O), and resuspension buffer (PBS with 1% BSA).
!Sample_extract_protocol_ch1 = Tagmentation of genomic DNA was conducted using Illumina tagmentation kit. Fragmented products were isolated using MiniElute Reaction Purification kit(QIAGEN) and library was constructed using Illumina Nextera XT SetA indices.

!Sample_data_processing = Basecalls were performed using bcl2fastq v2.20. Alignment, filtering, peak calling and QC were performed using ENCODE ATAC-seq pipeline v. 2.1.3(https://github.com/ENCODE-DCC/atac-seq-pipeline).
!Sample_data_processing = ATAC-seq reads were trimmed using cutadapt 2.5 with auto adapter detection and aligned using bowtie2 with the options -X2000 to GRCh38(https://www.encodeproject.org/files/GRCh38_no_alt_analysis_set_GCA_000001405.15/).
!Sample_data_processing = Low quality and duplicated reads were removed.
!Sample_data_processing = Peaks were called using MACS2 with a q_value cutoff <= 0.01 and a max peak number returned of 300000.
!Sample_data_processing = Differential accessibility analysis was conducted with the CSAW package v 1.2846. A consensus set of peaks was obtained from the union of peaks across all input samples/replicates. Peaks lying within blacklist regions and with low signal (less than -3 log10CPM) were removed. Reads were counted in 300 bp windows genomewide and merged to a maximum width of 5 kb. Finally, counts were TMM normalized and significant differentially accessible peaks were identified based on a genome-wide (for global analysis) or local window ( <= 1 Mb) FDR correction.
!Sample_data_processing = Coverage tracks were computed by merged replicates where applicable using samtools merge and creating signal tracks using DeepTools bamcoverage using the reads per genomic bin normalization (RPGC) options in DeepTools with the pre-computed effective genome size.
