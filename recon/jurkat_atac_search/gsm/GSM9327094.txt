!Sample_data_processing = Raw Illumina outupt files were processed into fastq files filtered using the Cumulus V2.1.1 Cell Ranger workflow on the Terra platform. In the associated raw data fastq files, R1 corresponds to the forward genomic DNA read, R2 corresponds to the 10x cell barcode, and R3 corresponds to the reverse genomic DNA read.
!Sample_data_processing = For ORF barcode libraries, a custom Python script (shared in the linked manuscript, called process_ATAC_ORF_barcode.py) was used to process fastq files into a matrix of cell barcodes versus ORF barcodes, with counts of each ORF barcode observed in each cell. In the associated raw data fastq files, R2 corresponds to the 10x cell barcode, and R3 corresponds to the ORF barcode read. As described in feature_reference.csv, the ORF barcode is found in positions 19-28 of the R3 read.
